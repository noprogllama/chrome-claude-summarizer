# Claude Summarizer

現在閲覧中のWebページをワンクリックでClaudeに送信し、わかりやすい要約を取得するChrome拡張機能です。

## 機能

- **ワンクリック要約**: ツールバーのアイコンをクリックするだけでページを要約
- **キーボードショートカット**: ショートカットキーを設定すると素早く要約（要設定）
- **自動送信**: Claude.aiを開いて自動的にプロンプトを送信
- **わかりやすい要約**: 用語集、図解、平易な言葉での説明を含む要約を生成
- **モデル選択**: Sonnet 4.5 / Opus 4.5 から選択可能
- **プロンプトカスタマイズ**: オプション設定で自由にプロンプトを編集可能

## 要約の特徴

この拡張機能は以下のルールでClaudeに要約を依頼します：

1. **用語集の作成**: ページ内のアルファベット略語（CSS, API, MVCCなど）の正式名称と意味を一覧表示
2. **視覚的な説明**: 難しい概念はアスキーアートやMermaid記法の図で説明
3. **平易な言葉**: 小学生でも理解できるよう、専門用語には噛み砕いた説明を追加

## インストール

1. このリポジトリをクローンまたはダウンロード
2. Chromeで `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. `src` フォルダを選択

## 使い方

1. 要約したいWebページを開く
2. 以下のいずれかの方法で要約を開始：
   - ツールバーの拡張機能アイコンをクリックし、「Claudeで要約」ボタンを押す
   - キーボードショートカットを押す（要設定、下記参照）
3. Claude.aiが新しいタブで開き、自動的に要約リクエストが送信される

### キーボードショートカットの設定

1. `chrome://extensions/shortcuts` を開く
2. 「Claude Summarizer」の「現在のページをClaudeで要約」を探す
3. 好みのショートカットキーを設定（例: `Ctrl+Shift+S`）

## オプション設定

拡張機能の動作をカスタマイズできます。

### 設定画面の開き方

1. 拡張機能アイコンを右クリック → 「オプション」を選択
2. または `chrome://extensions/` → Claude Summarizer の「詳細」→「拡張機能のオプション」

### 設定項目

- **モデル選択**: Claude Sonnet 4.5（高速）または Opus 4.5（高性能）を選択
- **プロンプト編集**: 要約時に使用するプロンプトを自由にカスタマイズ
  - `{pageTitle}` - ページのタイトルに置換
  - `{url}` - ページのURLに置換

## 必要条件

- Google Chrome
- Claude.aiのアカウント（ログイン済みの状態で使用）

## 注意事項

- Claude.ai自体のページは要約できません
- Claude.aiにログインした状態で使用してください
- 要約の品質はClaudeの応答に依存します

## ファイル構成

```
src/
├── manifest.json    # 拡張機能の設定
├── background.js    # バックグラウンドスクリプト
├── content.js       # Claude.ai上で動作するスクリプト
├── popup.html       # ポップアップUI
├── popup.js         # ポップアップの動作
├── options.html     # オプション設定UI
├── options.js       # オプション設定の動作
└── icons/           # 拡張機能のアイコン
```
